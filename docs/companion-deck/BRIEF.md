## Intent

A companion deck for the Cosmic Pizza demo. Each slide frames one part of
`DEMO_INSTRUCTIONS.md`, so the presenter can introduce a topic, switch to the
live demo, and return to the deck.

Narrative spine: because AI-assisted development raises the volume of code to
review, this audience should evaluate Code Quality as a pull-request-native
quality gate, starting with a scoped pilot, so that quality issues are fixed
before merge.
