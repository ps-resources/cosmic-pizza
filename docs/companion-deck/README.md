# Companion slide deck

A 13-slide HyperFrames slideshow to present alongside the live Code Quality
demo in this repository. It has presenter mode and speaker notes, and it is a
navigable HTML deck, not a rendered video.

## Run it

```sh
cd docs/companion-deck
npm run dev      # presenter mode with notes
npm run check    # lint and layout checks
```

This needs Node.js. Click **Present** (or press **P**) to open the audience
display, and share that tab.
